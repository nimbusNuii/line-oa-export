01

ส่วนขยายนี้ทำอะไร

ช่วยผู้ดูแล LINE Official Account ส่งออกข้อมูลของบัญชีที่ตนเองดูแลอยู่ — ข้อความในห้องแชท โน้ต แท็ก ชื่อผู้ติดต่อ และลิงก์ไฟล์แนบ — ให้อยู่ในรูปไฟล์ CSV หนึ่งไฟล์ต่อหนึ่งห้องแชท รวมอยู่ในไฟล์ ZIP เพื่อดาวน์โหลดเก็บไว้เป็นสำเนาสำรอง

ส่วนขยายทำงานเมื่อผู้ใช้กดไอคอนบนแถบเครื่องมือเท่านั้น และทำงานเฉพาะบนหน้า chat.line.biz

02

ข้อมูลที่ถูกเข้าถึง

  • เนื้อหาการสื่อสารส่วนบุคคล — ข้อความในห้องแชท โน้ต แท็ก และลิงก์ไฟล์แนบ
  • ข้อมูลที่ระบุตัวบุคคลได้ — ชื่อ ชื่อเล่น และรหัสผู้ใช้ของผู้ติดต่อในห้องแชทนั้น
  • ข้อมูลถูกอ่านผ่าน API ของ chat.line.biz ด้วยเซสชันที่ผู้ใช้ล็อกอินอยู่แล้วเท่านั้น ส่วนขยายไม่ได้เพิ่มสิทธิ์ใด ๆ ให้ผู้ใช้เกินกว่าที่มีอยู่บนหน้าเว็บ
  • ส่วนขยายไม่อ่านรหัสผ่าน ไม่อ่านคุกกี้ ไม่อ่านประวัติการเข้าเว็บ และไม่ทำงานบนเว็บไซต์อื่นนอกเหนือจากที่ระบุไว้ในตารางข้อ 03

04

ข้อมูลถูกส่งไปที่ไหน

ไม่ถูกส่งไปที่ใดทั้งสิ้น การประมวลผลทุกขั้นเกิดขึ้นในเบราว์เซอร์ของผู้ใช้ ผู้พัฒนาไม่มีเซิร์ฟเวอร์ที่รับข้อมูลจากส่วนขยายนี้ และไม่มีการเรียก API ของบุคคลที่สามใด ๆ

โค้ดจาวาสคริปต์ทั้งหมดที่ทำงานอยู่ในแพ็กเกจที่ติดตั้ง ไม่มีการโหลดสคริปต์จากภายนอกมารันขณะใช้งาน

05

ข้อมูลที่เก็บไว้ในเครื่อง

  • localStorage — การตั้งค่าที่ผู้ใช้เลือก และจุดที่ทำงานค้างไว้ เพื่อให้ทำต่อจากเดิมได้เมื่อถูกขัดจังหวะกลางทาง
  • IndexedDB — ผลลัพธ์ของห้องแชทที่ประมวลผลเสร็จแล้ว เพื่อไม่ต้องดึงข้อมูลซ้ำ

ทั้งสองอย่างอยู่ในเครื่องของผู้ใช้เท่านั้น ลบได้เองโดยการล้างข้อมูลเว็บไซต์ของ chat.line.biz หรือถอนการติดตั้งส่วนขยาย

06

การใช้งานข้อมูล

ผู้พัฒนาไม่ขายข้อมูลผู้ใช้ ไม่โอนข้อมูลให้บุคคลที่สาม ไม่ใช้ข้อมูลเพื่อวัตถุประสงค์อื่นนอกเหนือจากหน้าที่หลักของส่วนขยาย และไม่ใช้ข้อมูลเพื่อประเมินความน่าเชื่อถือทางการเงินหรือการให้สินเชื่อ

07

ความรับผิดชอบของผู้ใช้

ไฟล์ที่ส่งออกมีเนื้อหาการสนทนาของบุคคลจริง ผู้ใช้มีหน้าที่จัดเก็บและใช้งานไฟล์เหล่านั้นให้สอดคล้องกับพระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล (PDPA) นโยบายขององค์กรตนเอง และข้อกำหนดการใช้บริการของ LINE
